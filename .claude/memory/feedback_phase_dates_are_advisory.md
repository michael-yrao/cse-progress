**Set by the learner Aug 5, 2026,** on being shown that 0 of 5 Advanced Graphs algorithms had a 🟢 with
eleven days to the Aug 16 phase gate:

> *"im not too worried about not fully closing out advanced graph by the 16th, its why we have this system
> in place. if we are not finished, it is what it is, we keep carrying on until we finish it. add new
> problems slowly and keep trucking along the blank/shaky/cleans."*

**A phase end-date is a checkpoint, not a deadline.** An unfinished phase **carries forward** — that is a
normal outcome, not a failure state and not a thing to recover from. The exit criteria in
[[feedback-phase-exit-per-algorithm]] still hold exactly as written (per algorithm, recognition + execution,
≥1 🟢 each); what does *not* hold is treating the date as the thing those criteria must be met by.

**Why:** the comfort→interval engine is already the mechanism that decides when something is learned. A
calendar date cannot know whether Bellman-Ford stuck, and the tracker can. Grading against the date
double-counts — it re-asks a question the ratings have already answered, and answers it worse. The learner
built the system precisely so that "not done yet" resolves by continuing, not by escalating.

**How to apply:**

- **Never present a phase date as a countdown, a risk, or a thing that "closes on an unproven phase."**
  Report the state — *which algorithms have no 🟢* — and let the state drive the schedule. The state is the
  useful fact; the date adds nothing to it.
- **A slipped phase does not justify cramming.** It does not raise the daily cap ([[feedback-daily-cap]]),
  it does not license extra intake against a negative surplus
  ([[feedback-surplus-triggered-intake]]), and it does not make a protected rep movable.
- **"Add new problems slowly"** — intake stays gated on surplus and the difficulty tiers
  ([[feedback-difficulty-tiered-intake]]). A phase running long is a reason to keep intake *low*, never a
  reason to accelerate to "finish" it.
- **Do keep reporting the honest state.** This is not a request to soften findings — the learner responded
  to a blunt "0 of 5, eleven days out" by setting policy, not by asking for reassurance. Keep saying what
  is unproven; drop the deadline framing around it.
- Applies to **every** phase and every track (DSA, SD, AI), not just Advanced Graphs.
