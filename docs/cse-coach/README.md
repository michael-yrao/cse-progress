# cse-coach ↔ cse-progress

Everything in this folder is about the **seam between the two repos** — not about studying.

- **cse-coach** is the framework: the skill, the workflow conventions, the interval engine's logic.
- **cse-progress** (this repo) is the data: my tracker rows, my schedules, my solutions, my notes.

Anything that only makes sense when you're holding both repos at once belongs here. Anything about
DSA, system design, or AI engineering belongs in [`../foundations/`](../foundations/) instead.

## What's here

| File | What it's for |
|------|---------------|
| [`ROADMAP.md`](ROADMAP.md) | The "make this forkable" backlog — separating framework from personal data |

## On ROADMAP.md's shelf life

It was written before cse-coach existed as its own thing, so most of its backlog describes work that
cse-coach either already does or is the right place to do. **Once cse-coach is public, re-read it and
delete what it has absorbed** rather than carrying the whole file forward — the parts worth keeping
are the ones about *this* repo's data still needing a blank-slate path, not the ones about
genericizing the framework.

That deletion is the expected end state, not a failure to maintain it.
