## ⚙️ Gate change — thin-technique siblings no longer wait on `green:base` (Aug 23)

**Learner:** *"for the techniques without proper coverage, we can drop the gate on another problem
being green."* Adopted.

**stricter than the standard consolidation gate** (`🟡+`). For a *thin* technique it is counterproductive:
a second problem is another path to the technique's **first** 🟢 and trains the transfer that re-repping
one problem cannot — so gating coverage behind the base going green can deadlock a technique stuck at 🟡.

`green:base`. **One guard retained** — the thing `green:base` was a blunt proxy for:

> base a sibling just double-blanks.)
