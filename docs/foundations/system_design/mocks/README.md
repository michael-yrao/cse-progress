# Mock debriefs

One file per mock: `<YYYYMMDD>_<slug>.md`, written from
[`../templates/mock_debrief_template.md`](../templates/mock_debrief_template.md) **in the session, right
after the mock.**

**Two jobs.** The debrief is the evidence behind the comfort rating in
[`../mastery/design_progress.md`](../mastery/design_progress.md) — a 🟢 with no debrief is an assertion.
And its `❓ Open probes` section is the bank the **midweek deep-dive round** draws from; a design with no
open probes has nothing left to push on and the slot goes to the next question instead.

**Probes are bare questions, never summaries of the answer.** An answered probe is spent.
